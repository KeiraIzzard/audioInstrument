Documentation

Canopy (the Canopy project) is a browser-based instrument for studying. A Pomodoro timer grows a tree while you focus, and every leaf on the tree is a sound you can switch on and layer into a soundscape.

What it is and who it is for

People often study with ambient sound but have to pick a playlist and then leave it alone. This instrument makes the sound part of the study session. Each focus period earns you new leaves, so the soundscape you can build gets richer the longer you work. It is designed for students who want a calm, low-effort way to shape their own background sound, and it can be used with a mouse, touch or keyboard.

You do not need any musical knowledge. Every leaf already sounds good with the others, because all the pitched sounds come from one gentle set of notes.

Core interactive features

1. Pomodoro timer that grows the tree

Press Start focus. The timer follows the Pomodoro technique: 25 minutes of focus, then a 5-minute break, repeated for four sessions. After the fourth session there is a longer 15-minute break and the tree is complete. Pause stops the clock, Skip break jumps ahead during a break, and Reset tree (which asks you to confirm) starts over with a brand new tree. The timer sits in a small card at the bottom left of the screen so it is always in view.

While you focus, leaves bloom at random moments, four per session, so a finished tree has 16 leaves. The Demo speed switch (under the timer) makes one minute pass every second so you can see a whole cycle quickly.

2. Click a leaf and its sound keeps playing

Each leaf is a button. Click or tap it and its sound starts and keeps looping. Click another leaf and that sound joins in. Keep adding leaves to build a layered soundscape. Click a playing leaf again to stop just that sound, or use Stop all sounds. A playing leaf lights up with a soft glow, a brighter fill and a slowly pulsing halo, so you can tell what is on without relying on colour alone.

With a keyboard, press Tab to reach a leaf and Enter or Space to toggle it. The Volume slider (bottom right) sets overall loudness and Stop all sounds clears the mix. As more leaves play, each one is turned down slightly so the mix never gets harsh or distorted.

3. Rare leaves

Most leaves carry common sounds. Some carry a rarer, brighter bell sound in a paler colour. They appear less often, which makes each one feel like a find. Screen readers are told when a leaf is rare.

4. Light and dark mode

The page follows your device setting by default. The Switch to light/dark mode button overrides it, and your choice is remembered on this device.

Extended technique: Math.random()

The tree is never the same twice, because randomness decides what grows, where, and when. The code uses Math.random() in several deliberate ways rather than as one coin flip.

Where randomness is used
WhatHow it uses Math.random()Why
Which sound a new leaf getsA weighted pick across five sound tiers. Common tiers have large weights, the rare bell has a small one.Most leaves are easy to combine; rare ones feel special.
Which note a leaf playsA weighted pick from five notes (C, E, G, D, A) with the most settled notes weighted highest.Any combination of leaves sounds harmonious.
When leaves bloomThe focus period is split into four equal parts and one random moment is chosen inside each part.Growth is unpredictable but never bunches up or stalls.
Leaf shape and swayRandom lobe count, width, wobble and tilt for each outline.Every leaf is its own shape, like real foliage.
Branch shapeRandom bough angle and length, plus twig bends and small offshoots, when a tree is created.Each new tree has its own silhouette.
Where a sample startsEach sound begins at a random point in its audio file.Layers drift against each other instead of locking into a loop.
Catch-up for rare leavesIf 8 or more leaves have bloomed and none is rare, the rare weight is multiplied by 4.Players are not left waiting forever for a rare leaf.

The weighted choice works by adding up all the weights, picking a random number between zero and that total, and walking along the list until the running total passes the number:

function weightedPick(items) {
  var total = 0;
  items.forEach(function (i) { total += i.weight; });
  var r = Math.random() * total;
  for (var k = 0; k < items.length; k++) {
    r -= items[k].weight;
    if (r < 0) return items[k];
  }
  return items[items.length - 1];
}

Design system

Colour

The palette is deliberately calm and limited to muted purples and greens taken from the project mood board: deep aubergine and plum for the background, soft lavender for the trunk and secondary text, and sage green for the timer and anything that is growing. Light mode swaps to a soft off-white with the same hues darkened for contrast. All colours are CSS custom properties in tokens.css, so dark and light mode swap one set of values and nothing else changes.

Type

Kedebideri, a clear and friendly sans-serif, is used for all interface text because it stays readable at small sizes. Great Vibes, a flowing script, is used for the name and the timer's phase label, which gives the instrument its calm, hand-written character. Base text is 18px and grows with the screen.

Responsive and adaptive behaviour

The layout adapts at four breakpoints. Spacing and type scale up with the screen, the leaves get larger, and the controls rearrange.

The four breakpoints

The tree itself is recalculated from the size of the screen every time the window changes, so its branches always reach towards the edges of the area it has, rather than being scaled from a fixed picture.

Accessibility

  • Contrast. Text meets WCAG AAA (7:1 or more): in dark mode body text is about 15 to 17:1 and secondary text 11.4:1; in light mode 15.8:1 and 9.2:1. Button text is 8.7:1 (dark) and 9.2:1 (light). Lines and outlines are at least 3:1.
  • Size. Base text is 18px and grows on larger screens, buttons are about 45px tall, and the pop-up uses larger type.
  • Keyboard. Every control can be reached and used without a mouse, with a strong visible focus ring, and a skip link jumps straight to the tree.
  • Screen readers. The timer is announced as a timer, phase changes and new leaves are announced politely, and playing leaves report their on/off state.
  • Not colour alone. A playing leaf brightens, glows and pulses as well as changing colour, and screen readers hear each leaf's on/off state and whether it is rare.
  • Motion. If your device asks for reduced motion, the sway, pulse and drifting particles are switched off. High-contrast and forced-colour modes are supported.

Browsers and testing

The instrument is built with plain HTML, CSS and JavaScript plus the Tone.js audio library, which is included in the project, so it needs no install and works offline once loaded. It was built for the current versions of Chrome and Firefox. Browsers keep audio switched off until you interact with the page, so sound begins the first time you click a leaf.
